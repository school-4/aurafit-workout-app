> Премиальное кроссплатформенное мобильное приложение для тренировок в ультра-строгом монохромном стиле iOS. Поддерживает динамический остров (Dynamic Island), адаптацию весов при мышечном отказе, интерактивный таймер отдыха, систему из 8 рангов и полную автономную работу без интернета.

---

## 📱 Ключевые возможности

### 🎨 1. Черно-белый дизайн iOS и темы оформления
- **Pure OLED Black** (`#000000`): Абсолютный черный цвет с отключением пикселей на OLED/AMOLED матрицах смартфонов.
- **Obsidian Dark** (`#09090b`): Матовый титан с легкими монохромными градиентами и эффектом стекла (*backdrop-blur-xl*).
- **Titanium Light**: Контрастная светлая тема с титановыми акцентами.
- **Dynamic Island Live Activity**: В строке состояния эмулируется живой остров iPhone 16 Pro с индикацией активной тренировки.
- **Сенсорные пружинные микро-анимации**: Мягкий тактильный отклик (`active:scale-95`) для максимального комфорта при управлении с телефона.

### 🌐 2. Мультиязычность и профиль без цели
- **3 языка с запоминанием**: Русский (🇷🇺), English (🇬🇧), 中文 (🇨🇳) — выбор при первом входе и автоматическое сохранение.
- **Параметры тела**: Ввод веса, возраста и роста с моментальным расчетом ИМТ (Индекса массы тела).
- **Никаких вопросов о цели**: Пользователь сразу попадает в каталог проверенных программ.

### 🏋️ 3. Интеллектуальный плеер тренировок
- **Анимированные галочки подходов**: Пружинный отскок (`check-bounce`) с тактильным щелчком через Web Audio API.
- **Интерактивный таймер отдыха**: Автоматический запуск обратного отсчета между подходами с кнопками `+30с`, `Пропустить` и трехтональным звуковым сигналом финиша.
- **Кнопка «Не справился с весом»**: Интерактивная шторка, где атлет указывает фактические повторения и вес. Алгоритм снижает вес на 10–20% на последующие сеты и выдает совет тренера.
- **Счетчик тоннажа**: В реальном времени суммирует суммарный вес всех выполненных повторений.
- **Подсказки по технике**: Разбор правильной биомеханики для каждого упражнения.

### 🏆 4. Система из 8 атлетических рангов
1. 🦾 **Железный Новичок (Iron Novice)** (0 – 500 XP)
2. ⚡ **Стальной Атлет (Steel Athlete)** (500 – 1,500 XP)
3. 🛡️ **Бронзовый Воин (Bronze Warrior)** (1,500 – 3,500 XP)
4. ⚔️ **Серебряный Гладиатор (Silver Gladiator)** (3,500 – 7,000 XP)
5. 🏆 **Золотой Титан (Golden Titan)** (7,000 – 13,000 XP)
6. 🔥 **Платиновый Берсерк (Platinum Berserker)** (13,000 – 22,000 XP)
7. 💎 **Алмазный Джаггернаут (Diamond Juggernaut)** (22,000 – 36,000 XP)
8. 👑 **Бог Олимпа (God of Olympus)** (36,000+ XP)
*В конце тренировки атлет оценивает сложность по RPE (1-4), получает салют конфетти и очки опыта XP.*

### ⚡ 5. Отдельный AI-генератор планов
- Выделенная премиальная карточка над каталогом планов.
- Настройка частоты (2–6 дней в неделю), инвентаря (зал, гантели, свой вес) и приоритета (Full Body, Верх, Низ, Push-Pull-Legs).
- Алгоритм рассчитывает стартовые рабочие веса строго по формуле от веса, роста и возраста атлета.

## 📲 Установка и запуск на устройствах

### Вариант A: Мгновенная установка на телефон (PWA без App Store)
Приложение полностью поддерживает прогрессивный веб-стандарт с офлайн-кешированием:
- **На iPhone:** Откройте ссылку приложения в **Safari** -> Нажмите кнопку **«Поделиться»** -> Выберите **«На экран «Домой»»**.
- **На Android:** Откройте ссылку в **Chrome** -> Нажмите **«Установить приложение»** в баннере.

### Вариант B: Нативная сборка Android (APK)
В репозитории подготовлен полный проект для Android Studio:
```bash
# 1. Сборка веб-части и синхронизация
npm install
npm run build
npx cap sync android

# 2. Сборка APK через Gradle
cd android
./gradlew assembleDebug
# Готовый файл появится в: android/app/build/outputs/apk/debug/app-debug.apk
```
*Либо просто откройте папку `android` в Android Studio и нажмите **Build -> Build APK(s)**.*

### Вариант C: Нативная сборка iOS (Xcode)
```bash
npm install
npm run build
npx cap sync ios
npx cap open ios
# Запустите проект в Xcode на реальном iPhone или симуляторе
```

### Вариант D: Запуск на ПК (1 клик)
- Дважды кликните по **`Start_AuraFit.bat`** (встроенный легковесный веб-сервер Windows).
- Или откройте автономный монолитный файл **`AuraFit_iOS.html`** напрямую в любом браузере.
