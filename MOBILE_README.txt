================================================================================
          AuraFit iOS & Android — Полный готовый продукт (Full Release)
================================================================================

В этом пакете содержится ПОЛНЫЙ проект для всех платформ:
1. Native Android (Android Studio проект)
2. Native iOS (Xcode проект для iPhone/iPad)
3. Мобильное веб-приложение PWA (установка прямо с телефона в 1 клик)
4. Автономный файл для ПК

================================================================================
1. КАК УСТАНОВИТЬ НА ТЕЛЕФОН ПРЯМО СЕЙЧАС (Без App Store и Google Play):
================================================================================
Наше приложение поддерживает технологию Apple/Google PWA (Progressive Web App):

ДЛЯ IPHONE (iOS):
1. Открой ссылку приложения в Safari (например, локальный сервер или загруженный хостинг).
2. Нажми кнопку "Поделиться" (квадрат со стрелочкой вверх внизу Safari).
3. Прокрути вниз и нажми "На экран «Домой»" (Add to Home Screen).
4. Готово! На рабочем столе iPhone появится настоящая иконка AuraFit. 
   Приложение открывается во весь экран без адресной строки Safari, 
   с нативным виброоткликом, звуками и сохранением профиля офлайн!

ДЛЯ ANDROID:
1. Открой ссылку приложения в браузере Google Chrome.
2. Вверху появится баннер "Установить приложение AuraFit" 
   (или нажми три точки в углу -> "Установить приложение" / "Добавить на гл. экран").
3. На рабочем столе появится нативное приложение AuraFit.

================================================================================
2. КАК СОБРАТЬ NATIVE ANDROID APK (Для Android Studio):
================================================================================
1. Открой папку "android" в программе Android Studio.
2. Дождись автоматической синхронизации Gradle.
3. В верхнем меню выбери: Build -> Build Bundle(s) / APK(s) -> Build APK(s).
4. Готовый файл .apk появится в папке:
   android/app/build/outputs/apk/debug/app-debug.apk
5. Скинь этот .apk на любой телефон Android и установи в 1 клик!

================================================================================
3. КАК СОБРАТЬ NATIVE IOS APP (Для Mac и Xcode):
================================================================================
1. Открой проект на Mac:
   Дважды кликни на ios/App/App.xcodeproj (или через команду 'npx cap open ios').
2. В Xcode выбери свой iPhone или симулятор.
3. Нажми кнопку "Play" (Run) для установки на устройство, 
   или Product -> Archive для выгрузки в TestFlight / App Store.

================================================================================
4. БЫСТРЫЙ ЗАПУСК НА ПК:
================================================================================
- Дважды кликни "Start_AuraFit.bat" — откроется локальный сервер.
- Или просто дважды кликни "AuraFit_iOS.html" в браузере.
